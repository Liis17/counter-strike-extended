# HUD QoL — фидбек боя

Parent: [[Index]]
Связанные: [[Client/cs16-client]], [[Client/HUD-layout]]

## Назначение

Клиентские улучшения фидбека боя: индикатор направления урона, прозрачность
фона радара и настраиваемая длина kill feed. Все три — cvar'ы с
`FCVAR_ARCHIVE`, правки только в `cl_dll` (форк cs16-client).

## Cvar'ы

| Cvar | Диапазон | Описание |
|------|----------|----------|
| `cl_dmgindicator` | 0–2 (по умолчанию 1) | 0 — классические pain-спрайты вокруг прицела (штатный «pain compass»), 1 — красные дуги вокруг прицела, 2 — оба стиля одновременно |
| `cl_radar_alpha` | 0.1–1.0 (по умолчанию 1.0) | Прозрачность фона радара; размер радара по-прежнему задаётся scale элемента `Radar` в [[Client/HUD-layout]] |
| `hud_deathnotice_max` | 1–8 (по умолчанию 4) | Видимое число строк kill feed (было жёстко 4); командные цвета имёнkill-фида уже были штатными |

## Реализация

| Компонент | Путь | Что делает |
|-----------|------|------------|
| Дуги урона | `cl_dll/health.cpp` → `CHudHealth::DrawDamageArcs()` | Рисует 4 сегментированные дуги (по одной на фронт/тыл/право/лево) вокруг центра экрана через TriAPI-квады с `gHUD.m_WhiteTex`; интенсивность и затухание берёт из штатного `m_fAttack[4]` |
| Выбор стиля | `CHudHealth::Draw()` | Читает `cl_dmgindicator`; затухание `m_fAttack` применяет только последний рисуемый проход, чтобы стили не гасили друг друга |
| Фон радара | `cl_dll/hud/radar.cpp` → `DrawRadarBackground()` | Фон рисуется TriAPI-квадом с альфой `cl_radar_alpha` (pfnSPR_Set в движке всегда прижимает альфу к 255); режим сохраняет различие `cl_radartype`: additive для прозрачного радара, cut-out для opaque |
| Kill feed | `cl_dll/death.cpp` | Буфер увеличен до 8 записей; окно вставки/удаления и очистка слота управляются `MaxNotices()`; при переполнении слот за окном обнуляется `memset`, чтобы флаги старых записей не протекали в новые |

## Инварианты

- `m_fAttack[4]` остаётся единственным источником направления урона
  (заполняется `CalcDamageDirection()` из `MsgFunc_Damage`); дуги — только
  альтернативный рендер тех же данных.
- Дуги используют реальные пиксели (`* gHUD.m_flScale`, как прицел в
  `ammo.cpp`), а не HUD-координаты.
- Формат `rgDeathNoticeList` не менялся; вырос только размер массива.
