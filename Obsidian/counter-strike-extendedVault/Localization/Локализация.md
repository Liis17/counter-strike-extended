# Локализация

Parent: [[Index]]
Связанные: [[CSE/cse-structure]], [[Engine/xash3d-fwgs]], [[Client/cs16-client]]

## Назначение

Русские переводы UI и игровых строк Counter-Strike 1.6 / Half-Life для сборки
counter-strike-extended. Источник переводов — AI-перевод с английского (см.
`runtime/<gamedir>/resource/*_english.txt`). CS-термины оружия (AK-47, AWP,
M4A1, Desert Eagle, и т.д.) оставлены в оригинале; переведён весь UI-текст.

Хранятся в `src/cse/localization/` ([[CSE/cse-structure]]), в `runtime/`
попадают через `tools/install_localization.ps1`.

## Файлы

| Файл (в `src/cse/localization/`) | Цель в runtime | Формат | Кодировка |
|----------------------------------|----------------|--------|-----------|
| `valve/resource/gameui_russian.txt` | `runtime/valve/resource/gameui_russian.txt` | HL `"lang"` | UTF-16 LE BOM |
| `valve/resource/valve_russian.txt` | `runtime/valve/resource/valve_russian.txt` | HL `"lang"` | UTF-16 LE BOM |
| `valve/resource/mainui_russian.txt` | `runtime/valve/resource/mainui_russian.txt` | HL `"lang"` | UTF-16 LE BOM |
| `valve/resource/70_loc_russian.vdf` | `runtime/valve/resource/70_loc_russian.vdf` | VDF | UTF-8 без BOM |
| `cstrike/resource/cstrike_russian.txt` | `runtime/cstrike/resource/cstrike_russian.txt` | HL `"lang"` | UTF-16 LE BOM |
| `cstrike/resource/10_loc_english.vdf`, `10_loc_russian.vdf` | `runtime/cstrike/resource/` | VDF; CSE scoreboard short labels and Steam RP tokens | UTF-8 |

Кодировка `.txt` файлов **строго UTF-16 LE с BOM** (`FF FE`) — иначе парсер
движка (`MenuStrings.cpp`, `vgui_parser.cpp`) отбрасывает файл. VDF-файл
токенов Steam Rich Presence — UTF-8 без BOM (как оригинал `70_loc_english.vdf`).

> Примечание: `70_loc_russian.vdf` — это **Steam** (не Discord) Rich Presence
> токены для Half-Life (appid 70). Разрешаются Steam-клиентом при вызове
> `ISteamFriends::SetRichPresence` — см. [[CSE/rich_presence]]. Для CS (appid 10)
> Для CS (appid 10) `10_loc_russian.vdf` теперь содержит также scoreboard tokens.

Короткие токены `CSE_SB_K`, `CSE_SB_D`, `CSE_SB_PING`, `CSE_SB_BOT`, `CSE_SB_SPECTATORS` и
`CSE_SB_PLAYERS` добавлены для новой таблицы матча. `install_localization.ps1` дописывает английские
значения в существующий upstream `cstrike_english.txt` (не заменяя его), а русские значения живут
в проектном `cstrike_russian.txt`; C++ также имеет английский fallback.

## Механизм загрузки

`ui_language` (cvar, по умолчанию `"english"`) определяет язык. Выставлен в
`runtime/cstrike/vfs.cfg`:
```
ui_language "russian"
```
Флаг `fs_mount_l10n` оставляем `"0"` — локализованные файлы лежат прямо в
существующих `resource/` директориях, отдельная `<gamedir>_russian/`
не нужна.

### Кто что грузит

- **mainui движка** (`src/xash3d-fwgs/3rdparty/mainui/MenuStrings.cpp:456`):
  `gameui_<lang>.txt`, `valve_<lang>.txt`, `mainui_<lang>.txt`, `<gamedir>_<lang>.txt`
- **CS16Client** (`src/cs16-client/cl_dll/vgui_parser.cpp:237`):
  `valve_<lang>.txt`, `cstrike_<lang>.txt`, `<gamedir>_<lang>.txt`

### `mainui_russian.txt` — особенности

- Построен по шаблону `mainui_skeleton_everything.txt`
  (`src/cs16-client/3rdparty/mainui_cpp/translations/`) — self-contained,
  не зависит от gameui/valve.
- Ключи `StringsList_*` **намеренно опущены**: mainui заполняет их из
  `strings.lst`. Если их добавить с пустым значением `""`, они затрут строки
  из `strings.lst` пустотой.

## Установка

```powershell
# предпросмотр
tools\install_localization.ps1 -DryRun
# реальное копирование
tools\install_localization.ps1
```

Идемпотентно: повторный запуск безопасно перезаписывает целевые файлы.

## Что НЕ переведено

- `titles.txt` (внутриигровые HL-титры/обучающие подсказки) — отдельный
  формат, не классическая локализация; в CS-контексте почти не нужен.
- YaPB-боты уже имеют полный русский перевод в upstream
  (`src/cs16-client/3rdparty/yapb/cfg/.../lang/ru_*.cfg`).

## Важно: `render_picbutton_text` в gameinfo.txt

Локализация строк через `gameui_russian.txt` / `mainui_russian.txt` работает
только если кнопки рендерятся **текстом**, а не BMP-атласом. По умолчанию
`CMenuPicButton` использует `gfx/shell/btns_main.bmp` (найден в
`cstrike/extras.pk3`) — текст там запечён по-английски, и `L()` до него не
доходит. Флаг `render_picbutton_text 1` в `src/cse/cstrike/gameinfo.txt`
форсирует текстовый рендер. Подробности: [[CSE/menu]].
