# Профиль игрока

Parent: [[Index]]
Связанные: [[CSE/progression]], [[CSE/personalization]], [[Client/cs16-client]]

## Назначение

`UI_Profile_Menu` — отдельный экран прогрессии, доступный из главного и ESC-меню.
Он показывает текущий уровень/XP, lifetime-счётчики, три daily и две weekly-задачи,
полную историю матчей и агрегаты по картам.
Дополнительно отображается lifetime-таблица по всем 30 категориям оружия с kills/headshots.

## Граница `menu.dll` / `client.dll`

Профиль в `client.dll` остаётся единственным источником правды. `menu.dll` получает
сводные значения через cvar, а историю и статистику карт читает из файла, имя которого
публикует `cse_profile_file`:

| Cvar | Содержимое |
|------|------------|
| `cse_level`, `cse_xp` | Текущий уровень и XP |
| `cse_kills`, `cse_headshots`, `cse_deaths` | Lifetime K/D/HS-счётчики |
| `cse_round_wins`, `cse_round_losses`, `cse_match_wins`, `cse_match_losses` | Итоги раундов и матчей |
| `cse_daily_0..2`, `cse_weekly_0..1` | `id|progress|target|rewardXp|rewarded` |
| `cse_profile_file` | Файл активного local/SteamID-профиля |

Профиль не доверяет UI: выбор косметики повторно проверяется клиентской командой
`cse_skin`, а лимиты задач и награды применяются в `cse_profile.cpp`.

## Таблицы

- История включает завершённые матчи и ранние выходы после первого сыгранного раунда;
  такие записи помечены `Interrupted`.
- В истории отображаются карта, UTC-время начала, `K / D / HS`, XP сессии и результат.
- В статистике карт отображаются сыгранные раунды и lifetime `K / D / HS`.
- В статистике оружия отображаются все 30 стабильных слотов каталога и lifetime `Kills / Headshots`;
  таблица прокручивается при необходимости.
- При повреждённом или отсутствующем файле таблицы остаются пустыми, но summary и задачи
  продолжают работать через cvar.

## Методы

| Метод | Назначение |
|-------|------------|
| `CMenuProfile::_Init()` | Создаёт баннер, summary, таблицы задач/истории/карт/оружия и кнопку выхода; для каждой таблицы сначала назначает model, затем отключает сортировку |
| `CMenuProfile::Reload()` | Синхронизирует summary и перечитывает профиль при открытии |
| `CSEChallengeModel::Update()` | Разбирает сериализованный cvar задачи и показывает прогресс/награду |
| `CSE_LoadProfileTables()` | Читает блоки `history`, `maps` и `weapons` из KeyValues-профиля |
| `CSEWeaponModel` / `CSE_ParseWeapons()` | Строит прокручиваемую таблицу lifetime-статистики по оружию |
| `CSE_ProfileResult()` | Преобразует числовой результат и `interrupted` в подпись для UI |

Косметический каталог и применение моделей описаны в [[CSE/personalization]] и [[CSE/progression]].
